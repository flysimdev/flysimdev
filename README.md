### 👋 Hi, welcome aboard

I build free, open-source tools that make flight simulation look and feel more like the real thing.
My main project right now is **OrthoStreamXP**: photo scenery for X-Plane 12, streamed while you fly.

- 🛫 Currently working on **[OrthoStreamXP](https://github.com/flysimdev/OrthoStreamXP)** (beta)
- 🗺️ Interested in aerial imagery, texture streaming, terrain and anything that makes the view out of the window better
- 💬 Ideas, bugs or flight reports? Open an [issue](https://github.com/flysimdev/OrthoStreamXP/issues)
- ⚡ Fun fact: the DDS/BC1 texture encoder in OrthoStreamXP is hand-written

---

### 🛩️ Featured project

> **OrthoStreamXP** mounts a virtual file system over your existing X-Plane 12 scenery packages and builds photo textures from online aerial imagery the moment X-Plane asks for them. It loads the area ahead of your aircraft first and keeps a cache for the next flight.

|  |  |
|---|---|
| 📡 **Scenery on demand** | Imagery is downloaded as X-Plane needs it, not region by region |
| 🧭 **Look-ahead loading** | Follows your aircraft over UDP and prepares the area ahead of you |
| 🎚️ **Simple presets** | Balanced, Sharp, Ultra or Extra, with recommendations after each flight |
| 🎨 **Natural colours** | Evens out patchwork photos, seasonal tint, exposure control with live preview |
| 💾 **Managed cache** | Size limit, automatic eviction and a visual cache manager |
